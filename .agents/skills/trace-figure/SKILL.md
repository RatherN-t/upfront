name: trace-figure
description: Trace any financial figure in this repo back to the code or source that produced it. Use when a number in the docs, the prototype, or the pitch needs to be verified, challenged, or updated.
---

Trace `figure`, `$ARGUMENTS`, or the number under discussion back to its origin.

Every financial figure in this repo comes from exactly one of two places: `engine/FIGURES.json`, regenerated by `python3 tools/check.py figures`, or an external market source cited on a `[source: ...]` line. There is no third category. A number with no origin is a bug, not a rounding difference.

Resolve in this order. Search `engine/FIGURES.json` for the exact formatted string. If found, name the key and the engine function that computes it. If not found, search `docs/06-market-data.md` for a matching sourced datum. If still not found, the figure is untraceable and you say so plainly rather than reconstructing a plausible derivation.

When the figure is engine-derived, re-run the engine rather than trusting the JSON. Assumptions change and `FIGURES.json` is a build artifact.

State the inputs that would move the number most. For pricing figures that is usually fee drag, weighted average life, and the discount rate. For return figures it is business default probability, continuation on failure, and cash drag. Name the two that dominate rather than listing all of them.

If the figure is a return or yield, also report the downside figure that must accompany it. A yield stated without its p5 or p1 is a claim this repo does not permit.

Final: the figure, its origin key or source, the value the engine currently produces, and whether the doc is stale.
